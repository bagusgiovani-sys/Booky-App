## Critical Findings (must-fix)

1. **[BUG] "Load More" replaces results instead of appending** — `Home.tsx`, `Category.tsx`, `Search.tsx` all call `setPage(p => p + 1)` which triggers a new query returning only page N. Previous results disappear. Users see books vanish on every Load More click.

2. **[SEC] Unguarded `JSON.parse` in `authSlice.ts:12`** — `JSON.parse(localStorage.getItem('user') || 'null')` runs at module load time during store initialization, before the ErrorBoundary is mounted. Corrupted localStorage data throws a SyntaxError that crashes the entire app with a blank screen.

3. **[BUG] `useRecommendedBooks` in `BookDetail.tsx:98` lacks `enabled` guard** — fires immediately with `categoryId: undefined`, causing a wasted API request. Fires again when `bookData` resolves. Two fetches when one is correct.

## Major Findings (should-fix)

1. **[CHORE] `next-themes` in dependencies is completely unused** — no dark mode, no `ThemeProvider`, no `useTheme` anywhere in the codebase. Dead weight adding to bundle.

2. **[CHORE] `useCartCheckout` in `useCart.ts:14`** — queries `GET /api/cart/checkout` but zero components consume it. Dead export.

3. **[QUAL] `Category.tsx:128`** — empty state uses a bare `<p className="text-center text-gray-400 py-20">No books found</p>` instead of `<EmptyState>`. Every other list page uses `EmptyState`.

4. **[QUAL] Profile photo upload is a stub** — clicking the camera icon shows `toast.info('Photo upload coming soon')`. The UI presents this as a real feature. Either implement it or hide the camera button.

5. **[QUAL] `Checkout.tsx:27-29`** — `navigate()` called directly in render body (not inside `useEffect`). Works but is a React anti-pattern; React 19 strict mode double-invokes renders.

6. **[QUAL] `BorrowedTab` in `Profile.tsx:229`** — hard-codes `limit: 20` with no pagination. A heavy borrower silently gets a truncated list with no indication.

## Minor Findings (nice-to-fix)

1. **[QUAL] `BookFormPage.tsx:42`** — in edit mode, if `book.isbn` is null, fills the ISBN field with `` `ISBN-${Date.now()}` `` — a fake auto-generated ISBN that will be saved if admin clicks Save without noticing.

2. **[DX] Double `Suspense` in route tree** — `index.tsx` wraps in `<Suspense>`, and both `UserRoutes` / `AdminRoutes` add their own `<Suspense>`. The outer one is redundant (auth pages don't share the inner). Minor but confusing.

3. **[QUAL] `BookDetail.tsx` loading skeleton is one-off inline** — three animated `motion.div` divs instead of reusing `BookCardSkeleton` or a `BookDetailSkeleton`. Inconsistent with rest of app.
